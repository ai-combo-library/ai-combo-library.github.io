我们怎么测

在隔离项目中安装 claude-code-templates 的 code-reviewer 模板，让其执行代码审查；随后要求它实际调用 codebase-memory-mcp 的知识图谱，查找预先放入的缺陷，并核对模板安装和图谱辅助审查两项结果。

实际结果

claude-code-templates 的 code-reviewer 模板安装成功，并实际使用 codebase-memory-mcp 的知识图谱定位了预先放入的缺陷；两项结果检查均通过。

实际工作流怎么走

  1. 1. codebase-memory-mcp：整理上一环节的内容，转换成后续工具可以继续读取的结果。
  2. 2. claude-code-templates：获取原始资料，并把内容交给下一步。

继续补成可长期使用方案要做什么

  1. 固定输入样本和预期输出。
  2. 锁定依赖版本并在干净环境重新执行。
  3. 保留失败原因、产物和复测日期。
