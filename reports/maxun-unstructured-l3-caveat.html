maxun + unstructured

maxun 先采集网页内容，unstructured 再把采集结果处理成 JSON 元素和结构化文本，适合整理网页资料、竞品页面或公开资料归档。

maxununstructured
适合谁需要整理网页资料、竞品页面或公开资料归档的个人用户和小团队。
不适合谁不适合直接处理缺失、空白或并非 JSON 对象或数组的中间数据；也不适合要求已有大规模处理或全新环境验证结论的场景。
最大的限制交给 unstructured 的网页数据必须已经存在、内容非空，并且是本次任务目录内的 JSON 对象或数组。本次没有在全新环境中验证，也没有验证大规模数据处理能力；其他规模和环境下的表现均未验证。

我们怎么测

先用 maxun 生成实际网页数据，再将同一份数据交给 unstructured；随后检查这份中间数据是否存在、非空且为 JSON 对象或数组，并核对最终是否生成结构化 JSON。

实际结果

unstructured 确实读取了 maxun 产生的网页数据，并成功生成 JSON 结果；两项检查全部通过。
